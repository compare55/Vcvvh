JIowin project - run instructions

LOCAL TEST
1. Extract the ZIP.
2. Open the Jiowin-main folder.
3. Open index.html in a modern browser.

RENDER STATIC SITE
1. Upload the contents of the Jiowin-main folder to a GitHub repository (index.html must be at the published root).
2. In Render, create a Static Site and connect that repository.
3. Build command: leave blank.
4. Publish directory: . (a single dot) if index.html is in the repository root.
   If you uploaded the parent folder and index.html is inside Jiowin-main, set Publish Directory to Jiowin-main.
5. Deploy.

IMPORTANT
The bank account and withdrawal interface in this project is a demo only. It does not send real withdrawals or transfer real money. Real-money banking requires a secure server-side backend and a compliant payment/banking provider. Do not collect real bank details on a public demo site.
